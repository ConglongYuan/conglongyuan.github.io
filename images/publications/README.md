# Publication TOC images

Each publication has its own image file, referenced in `_data/publications.yml`.

## Replace an image

1. Find the paper below and replace its `.webp` file with the verified TOC / graphical abstract for that exact paper.
2. Preserve the filename. A 600 px wide image is sufficient; keep its original aspect ratio and aim for under 100 KB.
3. Set `image_alt` in `_data/publications.yml` to a concise description of the real image. If using JPG or PNG instead, also change `image` to that filename.
4. Commit the image and any data changes. The page uses a 3:2 frame with `object-fit: contain`: artwork is never cropped or stretched.
